project for MC testing students

This project will be used for testing students. All questions will be multiple choice. There is a maximum of 6 answer options per question.

Students can do 2 types of quizes:
1.  A quiz a teacher has setup
2.  A quiz that is randomly generated based on a subject

Students can also see the results of the quizes. After each question, the result is shown and an explanation provided (fast feedback cycle)

Teachers can add questions to the system, and combine questions into a quiz.
The teacher can also see the results of the quizes.

Teachers must be logged in to use the system. Students only have to provide a name, and can choose to store the result or not.
